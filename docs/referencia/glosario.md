# Glosario

**Alias de correo:** dirección que Odoo usa para crear registros a partir de
mensajes entrantes.

**Borrador:** factura de proveedor todavía no contabilizada.

**Catálogo:** lista de modelos publicada por el servicio de IA.

**Contrato estructurado:** conjunto exacto de campos y tipos que debe devolver
el modelo.

**Endpoint:** dirección HTTP concreta de una API.

**Fallback o respaldo:** segundo modelo usado únicamente ante determinados
fallos del principal.

**Huella SHA-256:** identificador calculado a partir del contenido del archivo
para detectar copias exactas.

**Modelo documental:** modelo capaz de recibir y comprender imágenes o
documentos.

**OpenAI-compatible:** servidor que implementa el contrato HTTP esperado de
catálogo y chat; no implica que use modelos de OpenAI.

**Prompt:** instrucciones de extracción enviadas al modelo. El cuerpo del
correo no se incorpora como instrucción.

**Sonda visual:** prueba controlada que comprueba si un modelo puede leer una
imagen.

**SSRF:** ataque que intenta que el servidor llame a direcciones internas o no
autorizadas. Por ello las redes privadas están bloqueadas por defecto.

**Trabajo o documento:** unidad independiente de procesamiento asociada a un
adjunto.
