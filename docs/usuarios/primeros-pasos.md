# Primeros pasos

## Antes de comenzar

Confirme con el administrador:

- que AI Processing aparece en **Contabilidad → AI Processing**;
- cuál es la dirección de correo de recepción;
- qué remitentes están autorizados;
- si el procesamiento es manual o automático;
- quién revisará y contabilizará los borradores.

## Primera prueba recomendada

1. Seleccione una factura sencilla y ya conocida.
2. Envíela como un único PDF al alias.
3. Abra **Contabilidad → AI Processing → Bandeja de facturas**.
4. Compruebe que aparece un correo con el remitente y el asunto correctos.
5. Si el modo es manual, pulse **Procesar candidatos**.
6. Espere a que el estado cambie a **Revisión contable**.
7. Abra el borrador y revise la pestaña **AI Processing**.
8. Compare todos los datos con el PDF.
9. Aplique el resultado solamente si las comprobaciones son correctas.

## Dónde encontrar cada cosa

| Menú | Uso |
|---|---|
| Bandeja de facturas | Correos recibidos y resumen de adjuntos |
| Documentos | Estado individual de cada archivo |
| Historial | Modelo, duración y resultado de cada intento |
| Configuración | Servicio, correo, modelos y límites; solo administradores |

## Señal de una prueba satisfactoria

Una prueba es satisfactoria cuando el documento original sigue disponible, la
extracción coincide con él, el proveedor existe con NIF/VAT exacto, no hay
duplicado y los datos se aplican únicamente a un borrador.
