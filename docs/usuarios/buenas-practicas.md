# Buenas prácticas

## Para quien envía

- Prefiera el PDF original del proveedor frente a capturas o fotografías.
- Escanee recto, completo y con resolución suficiente.
- Use un archivo por factura.
- Evite contraseñas, compresión y archivos innecesarios.
- No modifique el documento para “ayudar” al modelo.

## Para contabilidad

- Mantenga el modo manual durante la puesta en marcha.
- Revise con más atención proveedores nuevos, abonos y operaciones
  intracomunitarias o extracomunitarias.
- No interprete una confianza alta como aprobación fiscal.
- Investigue siempre una diferencia de destinatario o total.
- No fuerce un proveedor parecido si el NIF/VAT no coincide.
- Revise el documento original aunque el resultado no muestre alertas.

## Para responsables

- Defina quién puede enviar, revisar, aplicar y contabilizar.
- Muestree periódicamente resultados correctos e incorrectos.
- Controle consumo, latencia, fallos y uso del modelo de respaldo.
- Documente excepciones contables fuera del prompt de extracción.
- Conserve la factura original según la política legal y documental aplicable.
