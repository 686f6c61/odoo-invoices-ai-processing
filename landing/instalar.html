Guía de instalación

De Odoo limpio a tu primera factura de prueba.

01 · Requisitos

Prepara el terreno.

  • Una instalación operativa de Odoo 19 Community.
  • Acceso de administrador para instalar aplicaciones.
  • Contabilidad y Correo instalados en la misma base de datos.
  • Acceso al repositorio público o al paquete del módulo.
  • Una clave del servicio elegido o un servidor propio disponible.
  • Un buzón compartido para recibir facturas, preferiblemente por IMAP.

02 · Instalación

Seis pasos. Una prueba controlada.

Si Odoo está gestionado por otra persona, comparte esta página con ella y continúa desde el paso 4 cuando el módulo ya aparezca instalado.

  1. 01

    Obtén el módulo

    Descarga el repositorio y localiza ai_processing. Si utilizas el despliegue completo del proyecto, esa carpeta ya está incluida.

    Abrir repositorio ↗
  2. 02

    Añádelo a Odoo

    Coloca la carpeta ai_processing dentro de una ruta de complementos de Odoo. El servidor necesita también las librerías de lectura de PDF y cifrado declaradas por el módulo. 

    python3 -m pip install requests pypdf pypdfium2 cryptography

    En Docker, Coolify o un servicio gestionado, añade estas dependencias a la imagen; no las instales manualmente en cada reinicio.

  3. 03

    Instala AI Processing

    Reinicia Odoo, actualiza la lista de aplicaciones y busca AI Processing. Pulsa Activar. El módulo instala sus menús, permisos y tareas de procesamiento.

    Aplicaciones → Actualizar lista → AI Processing → Activar

  4. 04

    Conecta tu servicio

    Entra en la configuración guiada, elige OpenAI, OpenRouter, Ollama o tu servidor, y añade la clave de forma segura. Después, lee los modelos y selecciona una opción principal y otra de respaldo.

    Contabilidad → AI Processing → Configuración

    Evita el error más común

    En “nombre de variable de entorno” escribe algo como OLLAMA_API_KEY, nunca la clave completa. Si quieres pegar la clave, utiliza el campo protegido destinado a ella.

  5. 05

    Decide qué puede entrar

    Indica los dominios remitentes aceptados, el máximo de correos por minuto y cuántos adjuntos puede llevar cada mensaje. Después conecta un buzón compartido de facturas al correo entrante de Odoo.

    No necesitas configurar una cuenta SMTP saliente. AI Processing recibe facturas; no las envía.

    Elegir y conectar el correo ↓
  6. 06

    Haz una prueba conocida

    Envía una factura ya comprobada. Revisa que aparezcan el correo, el PDF correcto, el proveedor, los conceptos y el total. Aplica la propuesta al borrador solo cuando coincida con el documento.

    • El proveedor coincide por NIF o VAT.
    • Los conceptos permanecen separados.
    • Base, impuestos y total cuadran.
    • Los logotipos y firmas quedan ignorados.
    • La factura continúa en borrador.

03 · Correo

Un buzón compartido. No una cuenta personal.

Para Odoo instalado en tu servidor, crea una dirección estable para las facturas y conéctala por IMAP. El equipo podrá cambiar sin perder el circuito ni mezclar documentos con correos personales.

Dirección recomendada facturas@empresa.com Recepción dedicada · IMAP · SSL/TLS
  1. 01
    Crea el buzón

    Usa una cuenta compartida de tu proveedor de correo. No conectes el buzón personal de quien revisa las facturas.

  2. 02
    Conecta Odoo por IMAP

    En modo desarrollador abre los servidores de correo entrante, añade host, puerto, SSL/TLS y la credencial del buzón.

    Ajustes → Técnico → Correos electrónicos → Servidores de correo entrante
  3. 03
    Entrega el correo a AI Processing

    En “Crear un nuevo registro” selecciona AI Processing incoming email y activa Conservar adjuntos.

  4. 04
    Autoriza y prueba

    Añade primero tu dominio como remitente permitido, pulsa “Probar y confirmar” y envía una factura ya revisada.

¿Desde qué cuenta se puede enviar?

Desde cualquier dirección cuyo dominio hayas autorizado. El plugin filtra dominios, no obliga a una cuenta concreta.

¿Y el alias que muestra el módulo?

Es la ruta interna de AI Processing. Con el buzón IMAP, la dirección pública que compartes es facturas@empresa.com.

04 · Después

Actualizar sin perder el control.

  1. Haz copia de la base de datos y del filestore.
  2. Actualiza el código del módulo desde el repositorio.
  3. Actualiza ai_processing en una ventana de mantenimiento.
  4. Repite la factura de prueba antes de reabrir la entrada de correo.

Las claves siguen fuera de Git y los borradores existentes permanecen sujetos a revisión humana.

05 · Ayuda rápida

Si algo no aparece, empieza aquí.

No encuentro el módulo

Comprueba la ruta de complementos, reinicia Odoo y actualiza la lista de aplicaciones.

La clave parece inválida

Distingue entre el nombre de la variable y la clave. El nombre solo admite mayúsculas, números y guiones bajos.

No aparecen modelos

Guarda primero el servicio y la credencial. Después pulsa “Leer modelos” y elige uno capaz de leer documentos.

El alias no tiene dirección

Si usas un buzón IMAP dedicado, envía la prueba a ese buzón. El alias pertenece al enrutamiento interno del módulo.
