# Landing de AI Processing

Landing estática de la extensión para Odoo 19.

- `index.html`: presentación del producto.
- `instalar.html`: guía de instalación, primera configuración y prueba.

## Vista local

```sh
python3 -m http.server 8080 --directory landing
```

Después, abre `http://127.0.0.1:8080/`.

## Dirección visual

Combina precisión editorial con neobrutalismo controlado: retícula corporativa,
tipografía de gran escala, bordes negros, colores planos y sombras desplazadas.
No usa fuentes, imágenes, JavaScript ni dependencias externas.

## Antes de publicar

- Confirmar que `https://ai-processing.686f6c61.dev/` será el dominio definitivo.
- Convertir `og-image.svg` a `og-image.png` si vuelve a generarse el recurso.
- Añadir la plataforma de analítica y el aviso legal que se decidan.
