## Comunicar una vulnerabilidad

No publiques claves, facturas, datos personales ni detalles explotables en una
issue pública.

Utiliza la opción **Security → Report a vulnerability** del repositorio para
abrir un aviso privado. Incluye:

- versión afectada;
- pasos mínimos para reproducir;
- impacto observado;
- configuración relevante sin secretos;
- propuesta de mitigación, si la conoces.

Se confirmará la recepción antes de publicar detalles o una corrección.

## Límites operativos

AI Processing prepara borradores. No debe recibir permisos para publicar
asientos, ordenar pagos o modificar credenciales bancarias. Mantén las claves
en el gestor de secretos del servidor y prueba las actualizaciones con una
factura conocida.
